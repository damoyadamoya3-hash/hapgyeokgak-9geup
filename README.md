### 문제 유형
- **OX** — 한 문장의 참·거짓을 즉시 판단. 헷갈리는 지점을 빠르게 훑는 용도
- **객관식** — 기출과 같은 4지선다. 지문이 붙는 독해 문항 포함
- **빈칸(cloze)** — 이론 카드의 핵심 문장에서 한 부분을 가리고 고르게 한다

모든 문항에 해설이 붙어 있고, 상당수에 암기 팁이 따로 달려 있다.

학습 계획 카드는 날마다 **남은 복습 · 새 문제 · 약점 보강 · 오늘 읽을 이론 카드 한 장**을 짚어 준다. 이론 카드와 약점 보강 문제는 모두 과목 평균보다 **해당 단원의 실제 정답률**을 먼저 본다. 5회 미만의 작은 표본은 중립값 쪽으로 완화하며, 최근 50개 풀이 안에서 같은 범위를 5문항 이상 풀었다면 최근 정답률을 최대 70%까지 반영해 오래된 누적 평균에 약점이 묻히지 않게 한다. 약점 보강은 80점 미만 단원 중 세트 분량만큼 최대 3곳을 한 문항씩 먼저 포함하고, 남은 자리는 가중 확률로 채운다. 플레이 상단에는 실제 배정된 약점 단원을 표시한다. 세트를 마치면 **복습·새 문제·보강별 성취와 방금 가장 막힌 단원**을 따로 보여 주고, 전체 오답 더미가 아니라 **이번에 틀린 문항만** 즉시 다시 풀 수 있다. 이론 68장을 모두 읽은 뒤에도 약한 범위의 오래된 카드는 하루 한 장 다시 돌아온다. **계획대로 시작**을 누르면 문제 분량을 최대 30문항의 한 세트로 섞어 바로 시작하고, 복습·새 문제 칸만 따로 눌러 집중할 수도 있다. 새 문제는 가장 최근 모의고사에서 **과락(40점 미만)한 과목이 있으면 그쪽으로**, 없으면 아직 가장 덜 본 단원부터 낸다 — 어디부터 손대질 고르는 일 자체가 시작을 미루게 하기 때문이다. 복습은 새 문항이 남아 있는 동안 한 세트의 절반부터 배정하며, 한쪽 재료가 부족하면 다른 쪽이나 약점 보강으로 정확한 세트 분량을 채운다.

처음 열면 홈 맨 위에 **시작 안내**가 뜬다. 이론 카드 한 장 읽기 → 스토리 퀘스트 한 판 → 시험일 등록의 세 단계를 순서대로 짚어 주고, 각 단계를 누르면 해당 화면으로 바로 넘어간다. 20문항을 풀면 저절로 사라지고, 그 전에 닫아도 다시 나타나지 않는다.

홈 맨 위에는 **학습 계획 카드**가 있다. 설정에서 시험일을 넣으면 D-day와 함께 남은 문항을 남은 날로 나눈 **오늘의 목표 문항 수**를 계산해 준다. 그 목표선은 하루 동안 고정되고 이미 푼 만큼만 줄어들기 때문에, 공부할수록 목표까지 함께 내려가거나 같은 분량을 다시 시키지 않는다. 오늘 진도는 **서로 다른 문항 수**로 세므로 같은 오답을 즉시 다시 풀어도 계획된 새 문제·복습이 끝난 것으로 사라지지 않는다. 목표는 하루 10~120문항 사이로 제한되며, 남은 날에 전부 보기 어려운 상황이 되면 숫자를 부풀리는 대신 약한 단원과 오답노트로 좁히라고 알려 준다.

### 이론 도감이 하는 일

행정법과 교육학은 해설만 읽어서는 체계가 잡히지 않는다. 그래서 단원별로 **비교표 · 판례 · 암기 팁**을 담은 카드를 따로 두었다.

카드에 적어 둔 핵심 문장의 빈칸은 **자동으로 실제 문항이 되어** 문제 은행에 편입된다. 즉 카드를 읽고 → 그 자리에서 빈칸으로 외우고 → 며칠 뒤 복습 큐에 다시 나타난다.

## 왜 게임인가

수험 공부에서 가장 어려운 건 이해가 아니라 **매일 앉는 것**이다. 그래서 다시 열게 만드는 장치를 넣었다.

- **AI 테트리스** — 옆 패널에서 AI가 혼자 블록을 쌓는다. 꽉 찬 줄은 저절로 터지지 않고 금빛으로 대기하다가, **문제를 맞혀야 터진다.** 오답이면 쓰레기 줄이 올라온다. 학습 화면을 나가면 예약된 투하·소거와 렌더링을 모두 끝내 화면 밖 배터리 소모를 남기지 않는다
- **잭팟 릴** — 정답마다 확률적으로 슬롯이 돌아 XP 배수(×2 ~ ×20)가 걸린다. 릴이 하나씩 순차로 멈춘다
- **FEVER 모드** — 8콤보에 진입하면 15초간 XP 2배, 화면 연출과 BGM 템포가 바뀐다
- 레벨·칭호(9급 지망생 → 전설의 수험생), 코인, 업적 27종, 일일 임무 3개(8종 중 매일 배정)
- **연속 출석 보상** — 3·7·14·30·100일 사다리와 주간 출석 스트립
- 절차적 8비트 BGM과 효과음 — 오디오 파일 없이 WebAudio로 생성

연출은 전부 코드로 만든다. 외부 이미지·영상·폰트 파일이 없어서 파일 하나로 어디서나 열린다.

### 학습 설계는 진짜다

게임 껍데기 안쪽은 교육학 교과서 그대로다.

- **간격 반복** — 라이트너 박스(0·1·2·4·7·15·30일)로 복습 시점을 계산하며, 마지막 박스도 30일마다 유지 복습
- **약점 우선 출제** — 정답률이 낮거나 복습 시점이 지난 문항에 높은 가중치를 주되, **가중치에 비례한 확률로 뽑는다**. 약점 보강 문제와 이론 카드는 표본 수를 보정한 단원 정답률과 최근 흐름을 함께 쓰고, 미학습과 실제 0%를 구분한다. 짧은 세트에서도 최약 단원이 빠지지 않도록 최대 3개 단원을 먼저 한 문항씩 포함하고, 나머지 모든 문항에는 최소 확률을 남긴다
- **인출 연습** — 다시 읽기가 아니라 답을 떠올리게 하고 즉시 피드백
- **변동비율 강화** — 잭팟이 매번 터지지 않는 것이 핵심이다
- **정답 균형** — 퀘스트·모의고사·보스는 세션 안의 OX가 한쪽으로 쏠리면 같은 단원의 반대 정답 문항으로 바꿔 끼우고, OX 스피드런은 O와 X를 같은 수만큼 뽑아 섞는다. 객관식은 세션마다 선택지 순서를 다시 섞는다. 한쪽으로 찍어서 맞는 일이 없어야 인출 연습이 성립하기 때문이다

`node tools/validate.js`는 데이터 오류뿐 아니라 **정답 편향**도 함께 보고한다. OX의 O비율, 정답이 가장 긴 선택지인 비율을 출력하므로 문항을 추가할 때 기준선을 확인할 수 있다.

## 실행

```bash
node tools/build.js
```

`dist/index.html`이 만들어진다. 더블클릭하면 브라우저에서 바로 열린다. 개발 중에는 프로젝트 루트에서 정적 서버를 띄워도 된다.

```bash
python -m http.server 8777
```

진행도는 브라우저 `localStorage`에 저장된다. 마지막 모의고사의 상세 답안지와 문항별 **복기 완료 상태**도 함께 보관되어 결과 화면을 닫은 뒤 **학습 분석 → 최근 답안지 다시 보기**에서 재열람할 수 있다. 기기를 옮길 때는 설정에서 **진행도 내보내기**로 코드를 복사해 새 기기에서 불러오면 최근 답안지와 복기 상태도 함께 이동한다. 계정 화면은 마지막으로 성공한 코드 복사 시점과 그 뒤의 풀이량을 보여 주며, 20문항 이상 공부하고도 한 번도 복사하지 않았거나 이후 100회·30일 이상의 변경이 쌓이면 다시 보관하도록 안내한다. 가져오기 전에는 이름표·풀이 수·문항 수와 실제 변경 건수를 미리 보여 준다. 같은 진도 코드를 기준으로 나뉜 기기는 **문항별 정답·오답 횟수와 날짜별 학습량**을 기기별 증가분으로 합쳐, 같은 문항을 양쪽에서 풀어도 한쪽 기록을 버리지 않고 같은 코드를 반복해서 넣어도 중복 계산하지 않는다. 서로 다른 예전 코드는 문항마다 더 앞선 한쪽 기록을 안전하게 선택한 뒤 다음 병합의 공통 기준을 만든다. 두 기기의 연속 학습일은 실제 날짜가 이어질 때만 합치고, 이론 카드는 더 최근 열람일과 더 많은 훈련 횟수를 함께 남긴다. XP·코인·소모품도 같은 방식으로 기기별 증감을 합쳐 보존한다. 외부에서 붙여 넣는 코드의 최근 답안지는 허용된 필드와 범위로 다시 정규화하고, 문제·답·상태 문구는 텍스트로만 렌더링한다. **덮어쓰기와 초기화**는 직전 상태를 자동 백업하고 계정 화면에서 한 번 되돌릴 수 있다. 백업 저장에 실패하면 현재 진도를 바꾸지 않는다. 브라우저의 기존 진도 JSON 자체를 읽지 못할 때도 손상 원본을 별도 보관하며, 저장 공간 부족으로 복제할 수 없으면 사용자가 원본을 밖에 복사하고 명시적으로 전환하기 전까지 그 저장 키를 덮어쓰지 않는다.

저장량이 무한정 늘지 않도록 일자별 기록은 180일, 모의고사 상세 답안지는 가장 최근 1회만 남긴다. 전 범위 100문항 답안지도 별도 회귀 테스트로 크기를 제한하며, 내보내기 코드는 날짜를 사전으로 묶어 압축한다.

오프라인 업데이트는 새 핵심 화면을 전부 캐시한 뒤에만 활성화된다. 같은 단일 파일을 `./`와 `./index.html`로 두 번 저장하지 않고 canonical `index.html` 한 사본만 보관해 첫 설치 다운로드와 캐시 사용량을 줄인다. 네트워크가 끊기거나 배포 파일이 일부 빠졌다면 직전 정상판을 유지하며, 같은 GitHub Pages 도메인에 있는 다른 프로젝트의 캐시는 건드리지 않는다.

## 문항 추가하기

`data/questions/` 아래에 파일을 만들고 `data/manifest.js`에 등록하면 끝이다.

```js
QB.add([
  { id:'edu-adm-999', subject:'edu', unit:'edu-adm', type:'ox',
    src:'기출 빈출논점',
    q:'학교회계의 회계연도는 3월 1일에 시작한다.',
    a:true,
    exp:'「초·중등교육법」상 학교회계는 학년도와 일치한다.',
    tip:'학교회계 3.1~2월말 / 국가회계 1.1~12.31' }
]);
```

객관식은 `type:'mcq'`에 `choices` 배열과 정답 인덱스 `a`를 준다. 지문이 필요하면 `passage`를 붙인다.

이론 카드는 `data/theory/`에 `QB.addTheory([...])`로 추가하며, `cloze` 배열에 `{{정답}}` 표시를 넣으면 문항이 자동 생성된다.

추가한 뒤에는 반드시 검사기를 돌린다.

```bash
node tools/validate.js
```

중복 id, 정답 인덱스 범위, 선택지 중복, 해설 누락, 미등록 단원·과목, 빈칸 표시 누락을 잡아 준다. 여기에 더해

- **해설과 정답의 정합성** — OX 정답이 참인데 해설이 "반대다"로 시작하거나, 해설이 "정답은 ②"라고 적었는데 실제 인덱스가 다른 경우
- **같은 논점 중복 출제** — 지문까지 포함해 비교하므로 문두가 공용인 유형은 오탐하지 않는다
- **정답 편향** — OX의 O비율, 정답이 눈에 띄게 긴 문항 수

를 함께 보고한다.

## 접근성

- **명암 대비가 WCAG AA 기준(4.5:1)을 넘는다** — 라이트·다크 양쪽에서 검사했다. 마킹 적색은 면(배경)용과 글자용(`--brand-ink`)을 나눠 두어, 밝은 바탕 위 글자에서도 대비를 잃지 않는다
- **터치 목표가 최소 44×44px** — `pointer: coarse` 환경에서만 여백을 넓혀, 마우스 환경의 조밀한 배치는 그대로 둔다
- **폰의 뒤로가기 버튼과 제스처가 동작한다** — 앱을 나가지 않고 이전 화면으로 돌아간다. 풀이 중에 누르면 그만둘지 먼저 묻는다
- **키보드만으로 전부 조작된다** — Tab 으로 이동, Enter/Space 로 선택. OX는 `O`/`X` 또는 좌우 화살표, 객관식은 `1`~`5`, 해설 창은 Enter 로 넘긴다
- `:focus-visible` 로 키보드 이동 시에만 3px 포커스 링을 표시한다(마우스 클릭에는 나타나지 않는다)
- 아이콘만 있는 버튼에 `aria-label` 을 붙였고, 토스트 알림은 `role="status"` 로 읽힌다
- 경험치·문제 풀이·보스 체력·과목 점수·도감 수집·시험 복기 막대는 현재값과 최댓값을 `progressbar` 로 제공하고, 날짜별 학습량과 기억 정착도 그래프에는 같은 수치를 풀어 쓴 텍스트 대안을 둔다
- 제한시간은 화면 낭독기에 자연어로 제공하고, 30·10·5·1분과 10초 경계만 조용한 상태 메시지로 알려 매초 낭독을 방해하지 않는다. 보스전 하트도 이모지가 아닌 `남은 기회 2/3`처럼 읽힌다
- `prefers-reduced-motion` 을 존중해 부팅·화면 전환·FEVER·잭팟·파티클 애니메이션을 정적으로 바꾸고 AI 테트리스를 자동 중지한다. 점수와 XP·잭팟 보상은 그대로 유지한다

## 키보드

PC 에서는 손을 마우스로 옮기지 않고 풀 수 있다. 선택지와 다음 버튼에 키가 표시된다.

| 키 | 하는 일 |
|---|---|
| `1` ~ `5` | 객관식 보기 고르기 |
| `O` / `X`, `←` / `→` | OX 답하기 |
| `Enter` 또는 `Space` | 해설을 닫고 다음 문제로 |
| 모의고사 `←` / `→` | 이전·다음 문항으로 이동 |
| 모의고사 `Enter` | OMR 답안지 열기 |
| 모의고사 `F` | 현재 문항 검토 표시 켜기·끄기 |
| 모의고사 `Delete` / `Backspace` | 현재 문항의 OMR 답안 지우기 |

터치 기기에서는 키 표시가 나오지 않는다.

## 검증

```bash
node tools/validate.js   # 문항 데이터
node tools/test.js       # 동작 회귀
node tools/build.js      # 단일 파일 번들링
```

`validate.js` 는 중복 문항·정답 범위·해설 정합·OX 편향·빈칸 품질을 보고, `test.js` 는 화면 없이 동작을 본다 — 일일 임무 보상 정산, 연속 학습 계산, 밀린 복습의 순서, 모의고사 OMR 일괄 채점·복구·상세 복기, 기기 간 병합, 저장 실패 처리. 여기 담긴 항목은 **전부 한 번씩 실제로 깨졌던 것**이다. 둘 다 GitHub Actions 에서 배포 전에 돌아, 하나라도 실패하면 사이트가 갱신되지 않는다.

## 문항 출처에 관하여

수록된 문항은 국가직·지방직 9급 교육행정직과 한국사능력검정시험에서 **반복 출제되는 논점**을 기준으로 새로 작성한 것이다. 특정 회차 기출문제를 그대로 옮긴 것이 아니며, 각 문항의 `src`에 근거를 표시해 두었다.

모의고사 시간과 2027년 과목 개편은 [인사혁신처의 9급 공채 시험 개편 안내](https://www.mpm.go.kr/mpm/comm/policyPR/mpmFocus/?cntId=191&mode=view), [국가공무원 채용 FAQ](https://gongmuwon.gosi.kr/rccom/ComBbRcrutTestSnthsGdFaqLst.do), [경기도교육청의 지방공무원 임용시험 제도 안내](https://www.goe.go.kr/resource/goe/na/bbs_2584/2026/01/c09919aa-1cfd-46d6-bb8a-e3d5ba4cb430.pdf)를 **2026-09-01에 다시 확인**해 구현했다. 한국사 과목 메뉴는 앱의 기존 4지선다 문제은행을 활용한 **한능검 대비 연습**이며, 실제 한능검의 문항 형식·배점까지 재현한 실전 모의고사는 아니다.

판례·결정례는 행정법 65건, 교육학 17건을 이론 카드 안에 붙여 두었고, 68장 모두에 **암기 팁과 사례**가 들어 있다(사례 총 167건). 카드의 **등급은 곷 읽는 순서**다 — **S**는 그 단원에서 가장 먼저 읽을 한 장(단원당 정확히 하나), **A**는 본편, **B**는 배경·심화이며 목록도 그 순서로 늘어선다. 법령과 판례는 작성 시점 기준이다. 개정이 잦은 영역(교육 법규, 행정기본법)은 실제 시험 전에 최신 조문을 확인하는 편이 안전하다.
