# Webtoon 3D

노트북 웹캠으로 머리 위치를 실시간 추적해, **일반 2D 모니터에서도 웹툰을 입체적으로**
보이게 하는 뷰어입니다. 화면을 창문처럼 취급하는 Off-Axis Projection(비대칭 투영)으로
모션 패럴랙스를 만들어, 머리를 좌우로 움직이면 콘텐츠가 실제 깊이를 가진 것처럼 밀립니다.

특수 안경도, 3D 디스플레이도 필요 없습니다. 필요한 건 웹캠 하나뿐입니다.

---

## 빠른 시작

```bash
cd webtoon3d
npm install
npm run dev
```

터미널에 표시되는 주소(기본 http://127.0.0.1:5173)를 브라우저에서 엽니다.

프로덕션 빌드는 다음과 같습니다.

```bash
npm run build     # 타입 체크 + dist/ 생성
npm run preview   # 빌드 결과를 로컬에서 확인
```

### 요구 사항

| 항목 | 내용 |
| --- | --- |
| 브라우저 | Chrome / Edge 최신 버전 권장 (WebGL2 + WebAssembly SIMD) |
| 환경 | 웹캠 접근에는 `localhost` 또는 HTTPS 가 필요합니다 |
| Node.js | 18 이상 |
| 대상 | 데스크톱 · 노트북 전용 (모바일 미고려) |

트래킹을 처음 켤 때 MediaPipe 모델과 WASM 런타임을 CDN 에서 내려받습니다(약 10MB).

## 사용법

### 1. 웹툰 불러오기

- 이미지 파일을 **창 위로 끌어다 놓거나**, 화 폴더를 통째로 드롭합니다.
- 상단의 `이미지 열기` / `폴더 열기` 버튼도 같은 일을 합니다.
- `URL 열기` 로 직접 이미지 주소를 한 줄에 하나씩 붙여 넣을 수도 있습니다.
- 파일은 자연 정렬(`1, 2, …, 10`)로 이어 붙여 하나의 긴 세로 스크롤이 됩니다.

#### URL 로 열 때의 제약

깊이 추정과 WebGL 텍스처 업로드 모두 이미지의 픽셀을 읽어야 하므로, **서버가 CORS 를
허용하는 주소만** 열 수 있습니다. 허용하지 않는 주소는 실패로 표시됩니다.

> 이 뷰어는 사용자가 직접 지정한 이미지 파일과 주소만 다룹니다. 특정 사이트에서
> 콘텐츠 목록을 긁어 오거나, 로그인·결제로 보호된 콘텐츠를 우회해 가져오는 기능은
> 들어 있지 않으며 앞으로도 추가하지 않습니다. 본인이 정당하게 접근 권한을 가진
> 이미지를 사용하세요.

### 2. 트래킹 켜기

상단 `트래킹 켜기` 를 누르면 웹캠 권한을 요청합니다. 허용하면 상태 표시가
`얼굴 인식 중` 으로 바뀌고, 머리를 좌우로 움직일 때 화면이 반응하기 시작합니다.

이미지를 불러오기 전에도 배경에 층 구조 데모가 떠 있어 효과를 미리 확인할 수 있습니다.

## 효과가 약하게 느껴진다면

입체감은 **화면의 실제 크기를 얼마나 정확히 알려 주었는가**에 크게 좌우됩니다.
비대칭 절두체가 물리 좌표를 기준으로 세워지기 때문입니다. 설정(⚙)에서 조정하세요.

1. **화면 대각선** — 노트북 사양에 적힌 인치 값을 그대로 넣습니다. 가장 중요합니다.
2. **웹캠 화각** — 기본 62°. 머리를 조금 움직였는데 화면이 과하게 움직이면 값을 올리고,
   반대면 내립니다.
3. **양안 간격** — 거리 추정의 기준입니다. 앞뒤로 움직일 때의 반응이 어색하면 조정합니다.
4. **웹캠 위치** — 화면 상단 테두리에서 렌즈까지의 거리(cm).
5. **시차 강도** — 물리적으로 정확한 값은 `1.00` 입니다. 그 이상은 의도적인 과장으로,
   효과를 확인할 때 `1.5~2.0` 으로 올려 보면 움직임이 뚜렷해집니다.
6. **깊이 강도** — 콘텐츠가 화면 뒤로 물러나는 정도와 깊이맵 변위의 크기입니다.

조명이 어둡거나 역광이면 얼굴 인식이 불안정해집니다. 상태 표시가 `얼굴을 찾는 중…`
에서 넘어가지 않으면 조명을 먼저 확인하세요.

## 동작 원리

### Off-Axis Projection

일반적인 3D 렌더링은 카메라가 항상 화면 중앙을 정면으로 바라보는 대칭 절두체를 씁니다.
이 뷰어는 대신 **화면을 3D 공간에 고정된 직사각형 창문**으로 두고, 눈 위치에서 그 창문의
네 모서리를 향하는 비대칭 절두체를 매 프레임 다시 세웁니다
(Kooima, *Generalized Perspective Projection*).

눈이 창문 중앙에서 벗어나면 좌우 절두체가 비대칭이 되고, 창 너머의 물체는 눈 움직임과
반대 방향으로 밀립니다. 이 어긋남이 우리가 일상에서 깊이를 읽는 단서인 모션 패럴랙스이고,
그래서 양안 시차가 없는 평면 모니터에서도 깊이가 느껴집니다.

화면 밖으로 새어 나가는 부분은 절두체 자체가 잘라 내므로 별도 마스킹이 필요 없습니다.
절두체의 경계가 곧 창틀입니다.

### 머리 위치 추정

MediaPipe Face Landmarker 가 468점 얼굴 메시를 뽑으면, 그중 양쪽 눈 바깥 코너와 미간을 씁니다.

핀홀 카메라 모델에서 거리는 다음과 같이 구합니다.

```
초점거리(px) = (영상 폭 / 2) / tan(화각 / 2)
거리 z       = 실제 양안 간격 × 초점거리 / 화면상 양안 간격(px)
```

양안 간격은 개인차가 작아(성인 평균 63mm) 별도 캘리브레이션 없이도 쓸 만한 정확도가
나옵니다. 좌우·상하 위치는 같은 초점거리로 역투영해 얻습니다.

이렇게 얻은 좌표는 **웹캠 렌즈** 기준이므로, 웹캠과 캔버스 중심의 상대 위치를 더해
캔버스 기준으로 옮깁니다. 창 모드에서 창을 옮겨도 성립하도록 창 위치까지 반영합니다.

### 떨림 억제

랜드마크 좌표에는 지터가 섞여 있는데, 단순 저역 통과 필터로 지터를 없애면 이번에는
움직임이 굼떠집니다. **1€ Filter** 는 추정 속도에 따라 컷오프 주파수를 올려, 정지 상태의
안정성과 빠른 움직임의 반응성을 함께 잡습니다. 설정의 `떨림 억제` 슬라이더가 이 필터의
`minCutoff` 와 `beta` 를 함께 조정합니다.

렌더 쪽에도 얕은 지수 감쇠를 한 겹 더 둬서, 프레임이 잠깐 끊겨도 화면이 튀지 않습니다.

### 깊이 처리

페이지는 깊이맵을 정점 변위로 적용하는 격자 평면으로 그립니다. 깊이가 붙으면 페이지가
평면이 아니라 기복을 갖게 되고, 비대칭 투영과 맞물려 층마다 다른 속도로 밀립니다.

현재 제공되는 방식은 세 가지입니다.

- **없음 (평면)** — 페이지 전체를 하나의 평면으로 둡니다. 가장 가볍습니다.
- **간이 (밝기 기반)** — 밝기와 국소 대비를 섞어 부드러운 유사 깊이를 만듭니다. 모델
  다운로드 없이 즉시 동작하며, 웹툰처럼 선화 대비가 뚜렷한 그림에서 층 분리가 그럴듯하게
  나옵니다.
- **Depth Anything V2 Small** — Transformers.js 로 실제 단안 깊이 모델을 돌립니다.
  처음 선택할 때 모델(약 50MB)을 내려받고, WebGPU 를 지원하면 그쪽으로 실행합니다.

#### 긴 이미지의 타일 추정

웹툰 한 컷은 세로로 극단적으로 길어(1:10 이상도 흔합니다) 통째로 모델에 넣으면
정사각형에 가깝게 리사이즈되며 세로 정보가 뭉개집니다. 그래서 정사각형에 가까운 타일로
25% 씩 겹치게 잘라 각각 추정합니다.

타일마다 독립적으로 정규화된 값이 나오므로 그대로 이으면 경계에 단차가 생깁니다.
겹침 구간에서 최소제곱으로 `a·x + b` 를 맞춰 앞 타일과 같은 척도로 되돌린 뒤, 겹침
구간을 선형으로 페이드하며 누적해 이어 붙입니다.

깊이맵은 페이지별로 캐시되므로 같은 이미지를 스크롤로 여러 번 지나쳐도 한 번만 계산합니다.
세 방식 모두 `DepthProvider` 인터페이스 뒤에 있어, 렌더러는 어느 쪽이 붙었는지 모릅니다.

## 성능

- **텍스처 윈도잉** — 화면 위아래 한 화면 범위 안의 페이지만 GPU 에 올리고, 벗어나면
  즉시 해제합니다. 수십 장짜리 화도 일정한 메모리로 봅니다.
- **지연 세분화** — 깊이맵이 도착한 페이지만 격자로 다시 만듭니다. 평면 페이지는 정점
  4개짜리 사각형 그대로입니다.
- **지연 로딩** — MediaPipe 는 트래킹을 켤 때, Transformers.js 와 ONNX 런타임은 깊이
  모델을 고를 때 비로소 내려받습니다. 초기 로드에는 어느 쪽도 포함되지 않습니다.
- **프레임 중복 제거** — 웹캠이 새 프레임을 내놓지 않았으면 추론을 건너뜁니다.
- **픽셀 비율 상한 2** — 고해상도 노트북에서 렌더 비용이 폭증하지 않게 합니다.
- **깊이 캐시** — 같은 이미지는 다시 계산하지 않습니다.
